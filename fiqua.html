Quant Finance

Derivative Pricing Library

An options-pricing library built in layers: instruments, pricing engines, and a batch valuation pipeline that shares work instead of repeating it.

Overview

This is a quantitative finance library built on top of my numerical methods library, covering equity option pricing, Greeks, implied volatility, and valuation of a batch of trades at once. It's a portfolio project, built in layers that are each independently testable. Equities came first, and the core underneath is built to hold a second asset class later, such as interest rate products under a short-rate model, without needing to be reshaped.

Architecture

Every instrument is routed to a pricing engine, priced under a chosen market model, and the result is assembled and handed back. This sequence is written generically, with equities plugged in through the same shared registrations any future asset class would use, so a bond or a rate product could go through it too.

Two pricing engines exist for the same option: a closed-form formula and a numerical solve of the pricing equation by finite differences. Both are registered as alternates for the same product, so a trade can be priced by either, and running both against one contract is how each is checked against the other. Routing can be set per metric rather than per trade: one Greek can come from the closed-form engine while another is read off the numerical solution, or any single metric can be forced onto a bump-and-reprice approach regardless of what its engine would otherwise compute directly.

A batch of trades is priced together rather than one at a time. Every trade is resolved first, its requested metrics are split across whichever engines they're routed to, each engine prices its whole share of the batch in one pass, and the results are stitched back into a single row per trade. A trade that depends on more than one engine fails as a whole if any of them fails. An engine is built the first time a trade needs it and reused for the rest of the batch, with shared calculations cached rather than repeated.
